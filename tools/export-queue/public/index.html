      How do I get the path?

      The easiest way is Browse…: it shows the client drives exactly as the export PC sees them.

      On a Mac

      1. In Finder, right-click the file (or Control-click it).
      2. Hold the Option key: the menu changes.
      3. Choose Copy “Poster.indd” as Pathname.
      4. Click in the box above and press Cmd+V.

      On Windows

      1. In File Explorer, hold Shift and right-click the file.
      2. Choose Copy as path.
      3. Click in the box above and press Ctrl+V.

      Several files at once work too: select them all first, then copy. Dragging a file onto this page can't work, because browsers keep a file's location private.
